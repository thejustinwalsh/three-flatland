## Scaffold a New Project

`create-three-flatland` generates a Vite starter with a running WebGPU sprite scene, linting, unit and
Playwright tests, and agent guidance files.

<Tabs syncKey="pkg">
  <TabItem label="npm" icon="simple-icons:npm">
    ```bash
    npm create three-flatland@latest
    ```
  </TabItem>
  <TabItem label="pnpm" icon="simple-icons:pnpm">
    ```bash
    pnpm create three-flatland
    ```
  </TabItem>
  <TabItem label="yarn" icon="simple-icons:yarn">
    ```bash
    yarn create three-flatland
    ```
  </TabItem>
  <TabItem label="bun" icon="simple-icons:bun">
    ```bash
    bun create three-flatland
    ```
  </TabItem>
</Tabs>

You are prompted for a project directory and a template. Pass both as arguments to skip the prompts:

```bash
npm create three-flatland@latest my-app -- --template three
```

| Template | Stack |
| --- | --- |
| `three` | Plain Three.js + WebGPU (`three/webgpu` + TSL) on Vite |
| `react` | React Three Fiber (`@react-three/fiber/webgpu`) on Vite |

`--overwrite` deletes everything in the target directory except `.git`, then scaffolds. Run `--help`
for the full flag list.

## Requirements

- **Three.js**: ^0.185.1 (required for TSL/WebGPU support)
- **React**: ~19.2.0 (for `three-flatland/react`; R3F alpha.3 requires `React < 19.3`)
- **@react-three/fiber**: 10.0.0-alpha.3 (for `three-flatland/react`)
- **Node.js**: >= 22 (LTS)

## TypeScript

three-flatland is written in TypeScript and ships with full type definitions. No additional `@types` packages are required.

See the [LLMs page](/three-flatland/llm-prompts/) for more prompts and machine-readable documentation.
